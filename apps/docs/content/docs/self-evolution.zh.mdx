自进化是工作区的 Prompt 治理工作台。打开工作区侧边栏的「自进化」，可以查看 [Agent](/agents) prompt 的版本历史与质量度量，用固定题库做防回归测验，并通过立法提案与知识库把观察结果转化为改进。

页面包含八个 Tab：总览、质量、版本、题库测验、Skill、立法提案、每日总复盘、知识库，默认打开「质量」。

## 总览

总览聚合各 Tab 的核心读数，默认显示六张卡片：Prompt 版本活动（各层级当前版本与最近变更）、质量读数（按时间窗统计，已剔除环境与供应商故障）、题库测验结论（基线与当前版本的读数对比）、提案池动态（提案指标待接入）、知识库沉淀（已注册目录与条目数）与 Skill 观测（数量与累计显式调用）。

## 质量

「质量」Tab 展示一个 Agent 的 prompt 运行度量看板。先用顶部的「对象」选择器选择一个 Agent（统计对象目前仅支持智能体），再用「时间窗」调整统计范围（默认最近 30 天）。

看板围绕七个维度取数：

| 维度 | 含义 |
|---|---|
| D1 注入成本 / 运行成本 | 每次运行注入的拼接提示词 token 中位数；单次运行消耗的总 token 中位数。 |
| D2 纪律性 | 纪律性中位分（满分 100）：每次运行从 100 分起算，违反一条可机械判定的条款扣一次分。 |
| D3 规则困惑度 | 拼接提示词的歧义风险评分，按运行态（普通成员态 / Leader task 态）分别评定，不合并、不平均。 |
| D4 轮次失败率 | 智能体收到的工具结果中被判定为错误的占比。 |
| D5 重试次数 | 需要一次以上尝试才完成的运行占比。 |
| D6 错误根因 | 原因指向 prompt 的失败次数；环境与供应商类失败已剔除。 |
| D7 一次过率 | 进入评审后无返工即通过的 Issue 占比。 |

「窗口内全部版本」把读数按 prompt 版本拆开：在版本时间线上点选两个版本，即可逐维度对比差值。点击「管理版本」跳转到「版本」Tab。

## 版本

「版本」Tab 是 prompt 的版本生命周期入口。核心规则只有一条：**每次生效变更都会追加一个版本，历史永不改写**。

版本线覆盖六类 prompt 载体：工作空间、项目、小队、智能体、自动化（Autopilot）与 Skill。本页不提供任何内容编辑：版本通过「建立快照」把统计对象当前生效的配置记录为一个新版本；要修改载体内容，请到各载体自己的管理入口操作。

先用顶部「对象类型」选择载体类型，再用「统计对象」选择具体对象；「工作空间」类型无需再选对象（即本工作空间本身）。未选择统计对象时页面只显示占位提示。

### 建立快照

1. 选好对象类型与统计对象后，点击右上角「建立快照」并确认。
2. 该统计对象当前生效的配置会被记录为一个新版本（来源标记「快照」），载体本身的内容不受影响。
3. 快照允许重复：内容没有变化也可以再次快照，每次都会追加一个新版本。
4. 快照版本的变更说明默认记录为「快照当前生效配置」。

<Callout type="warning">
快照与所有版本写入共用同一组门禁：载体当前生效内容为空或超过 200 KB 时快照被拒绝（400）；内容疑似包含凭据时同样被拒绝（422），并列出命中的规则、所在行与掩码样本。请先在载体自己的管理入口移除相关内容，再回来建立快照。
</Callout>

### 激活与回滚

版本列表按版本号倒序排列。每个版本带有来源标记（基线 / 编辑 / 回滚 / 自动快照 / 快照）、变更说明、创建日期、内容指纹前缀与质量评测角标；最新版本带「最新」标记。

把任意历史版本「切换到此版本」即完成回滚：该版本的内容会被复制为一个新的最新版本并立即生效，旧版本原样保留，由回滚产生的版本会额外显示「来自 vN」。之后随时可以再次激活更早的版本来撤销这次切换——历史只追加、不改写，每次切换都留有完整痕迹。

### 对比任意两个版本

点击两个版本号即可弹出两者的内容差异对比；点选第三个版本号会替换较早的选择，点击「清除选择」退出对比。

### 质量评测的版本绑定

质量评测把每次运行绑定到它领取时的 prompt 版本。每个版本行的角标显示该版本承载的运行次数，因此可以直接看到每次质量变化发生在哪个版本之后。

### 写权限

版本的读取对所有成员开放；「建立快照」与「切换到此版本」仅工作空间 Owner 可用（admin 不在其中），非 Owner 不会看到写操作入口。

## 题库测验

「题库测验」Tab 用同一套固定题库对每个 prompt 版本重复测验，给出「防回归读数」：以某个版本为基线，对比当前版本的读数分布（中位数、四分位距），并给出改善 / 持平 / 回归 / 无读数的判定。

- 读数是分布而不是单一分数；样本不足时不给对比。
- 测验从不阻断 prompt 版本发布，只记录质量如何变化。
- 「题库」面板管理固定题库：新增、编辑、停用题目。题面修改会开启新的修订号，读数只在同一题面、同一运行时与模型的结果之间比较。
- 题面必须自足，不得引用任何生产实体（Issue 编号、ID、链接），违规题面会被服务端拒绝。
- 题库的写操作仅工作空间 Owner 可用；「标准答案与评分项」仅 Owner 可见，且不会发送给被测 run。

## Skill

「Skill」Tab 展示 [Skill](/skills) 的版本记录与已观测使用：分配了哪些 Agent、显式调用次数、各版本 token 消耗中位数，以及版本读数对照——运行 token 中位数、重试占比、一次通过率，按使用组 vs 对照组比较。

版本差异是观察性数据，不能证明由 skill 引起；两侧各至少 5 个有效运行样本才展示差值。

恢复历史版本同样采用追加式：Owner 点击「恢复此版本」，该版本内容会成为新版本，分配关系不变。

## 立法提案

「立法提案」Tab 管理 Prompt 条款级改进草案，面向四个 Prompt 载体（工作区、项目、小队、Agent）。每条提案绑定目标章节与变更类型（新增条款 / 移除条款），附条款最终文本与证据锚（Issue 编号 + 引文）；提交审批前必须完成内容闸五答：层次归属、去留判据、代价声明、冲突裁决与重复检查。

提案状态流转：草稿 → 待 Owner 审批 → 已批准 → 已生效；门闸未过或被驳回的提案保留可查，可返工后重新提交或恢复为草稿。来源标记区分人工起草、每日总复盘自动生成与合并。

所有成员都可以起草、编辑并提交自己的提案；批准（含批量批准，单批最多 20 条）、驳回、恢复为草稿与执行生效仅工作空间 Owner 可操作。批准前必须在沙箱预览整个载体的全文 diff 并显式确认；执行生效会重新运行立法门闸，只有干净通过才写入生效配置。

## 每日总复盘

「每日总复盘」是底座内置的定时任务：读取回看窗口内已完成 Issue 的真实执行内容，提炼 Prompt 改进草案批量送入立法提案，运行全程不产生任何 Issue 评论。

配置区提供「启用定时运行」开关、「同时扫描 in_review 的 Issue」选项与「回看窗口（天）」，保存后生效；「立即运行」可手动触发一次复盘。运行记录列出每次运行的状态（成功 / 失败 / 运行中）、窗口、扫描 / 分析 / 新建 / 合并 / 去重跳过计数与错误信息。

LLM 未配置时，运行会记录一条指明缺失配置的失败记录。查看配置与运行记录对所有成员开放；修改配置与立即运行仅工作空间 Owner 可用。

## 知识库

「知识库」Tab 以只读方式镜像 bd memories 目录：已连接的守护进程会自动发现项目自带的 bd memories，也可手动注册本机目录。注册后可执行扫描（显示新增 / 更新 / 移除计数），并按 key 或内容搜索条目镜像。

镜像本身只读：唯一写路径是 Owner 对待采纳条目执行「采纳」，把内容转移到知识总库。注册、扫描、注销与采纳仅工作空间 Owner 可用。

## 权限一览

| 操作 | 权限 |
|---|---|
| 查看全部 Tab 与读数 | 所有成员 |
| 建立快照、激活（回滚）版本 | 工作空间 Owner |
| 题库新增 / 编辑 / 删除 | 工作空间 Owner |
| 恢复 Skill 历史版本 | 工作空间 Owner |
| 提案起草 / 编辑 / 提交审批 / 预览 / 返工 | 所有成员（限本人草案） |
| 提案批准 / 驳回 / 恢复为草稿 / 执行生效 | 工作空间 Owner |
| 每日总复盘配置 / 立即运行 | 工作空间 Owner |
| 知识库注册 / 扫描 / 注销 / 采纳 | 工作空间 Owner |
